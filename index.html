AutoTube AI

AutoTube AI is a personal software project for creating original short-form videos and managing uploads to a YouTube channel with the account owner's authorization.

Privacy PolicyTerms of Use

What it does

The project brings together script drafting, locally generated narration, licensed visual assets, video editing, and optional YouTube uploading. The owner decides which account to authorize. The application checks the destination channel before attempting an upload.

Google and YouTube access

AutoTube AI uses Google OAuth to request permission to identify the connected YouTube channel and upload videos on the owner's behalf. It does not ask for the owner's Google password. Authorization can be revoked in the Google Account's third-party connections settings.

Project status

This is an experimental, personally operated application, not a public software service. Features may change during development. The website does not collect sign-ups or accept payments.
